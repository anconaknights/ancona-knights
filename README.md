# Ancona Knights Site

A simple Christian and patriotic American single-page website.

## Files
- `index.html` — main page
- `style.css` — styling

## How to use
1. Download the folder (or clone this repo).
2. Open `index.html` in any web browser.
3. To put it online for free:
   - GitHub Pages: push these files to a GitHub repo and enable Pages.
   - Netlify / Vercel: drag the folder onto their drop zone.

## Customizing
- Edit the text directly in `index.html`.
- To add photos: drop image files in the folder and update the HTML with `<img src="your-photo.jpg" alt="description">` where you want them.
- Colors are defined at the top of `style.css` if you want to tweak them.
